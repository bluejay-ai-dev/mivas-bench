# Changelog

Each entry compares a regenerated export with the previously published Hugging Face
revision of `bluejay-labs/mivas-bench`. Comparison is plain JSON equality per column
between the old row and the new row for the same `task_id`. `exp_db_state` gives the
same result with and without the write-time `created_at` columns. Files are compared
byte for byte. This file is written by hand; everything else in this folder comes from
`scripts/export_dataset.py`.
